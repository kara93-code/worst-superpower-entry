Invent the most useless superpower in one line of 140 characters. A judge model ranks the field; the single winner takes the $2 pool. Free to enter.

## The entry

> The power to breathe underwater — but only with my head above the water.

A classic superpower, cancelled in the same breath: the hero's head never goes under, so the "power" is just ordinary breathing, announced with pride. One line, 72 characters.

## Run it

```sh
node main.ts
```

This writes the single line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set). No network, no randomness, no input — the same line every run.
